# Руководство по работе над проектом
## Получение root-доступа и настройка Яндекс Станции Макс (YNDX-0008 / YNDX-00052 / YNDX-00053)

Этот документ содержит технические сведения и обязательные ограничения для автоматизированных систем и разработчиков, которые изучают, изменяют, обслуживают или восстанавливают устройства Яндекс Станция Макс в рамках этого проекта. 

---

## 1. Характеристики устройства и памяти

```
Оборудование:
  - Модели: YNDX-0008 (базовая Макс), YNDX-00052 / YNDX-00053 (Макс с Zigbee)
  - SoC: Amlogic A311D (4 ядра Cortex-A73 @ 2,2 ГГц + 2 ядра Cortex-A53 @ 1,8 ГГц)
  - GPU: ARM Mali-G52 MP4 (драйвер /dev/mali0)
  - ОЗУ: 2 ГБ LPDDR4
  - Накопитель: 32 ГБ eMMC 5.1
  - ОС: Android TV 9 (Pie), 64-разрядная, ядро Linux 4.9.113
  - Архитектура: arm64-v8a

Целевая прошивка и смещения для эксплойта ядра:
  - Сборка 5000000921 (ro.build.display.id PPR1.180610.011.5000000921)
    - Указатель selinux_enforcing в ядре: 0x291352c
```

Указанное смещение относится к сборке 5000000921. Не используйте его для других сборок без отдельной проверки.

## 2. Жёсткие ограничения и правила

> [!CAUTION]
> **ПРАВИЛО 1: НЕ ИЗМЕНЯТЬ `/system`, `/vendor` ИЛИ `/boot`.**
>
> Разделы `/system` и `/vendor` защищены проверкой dm-verity при заблокированном загрузчике. Запись в эти разделы, изменение их файлов или неосторожное отключение dm-verity может вызвать неустранимый цикл загрузки и вывести устройство из строя.
>
> - Для постоянных файлов проекта используйте только `/odm` и `/data`.
> - `/odm` в штатном состоянии смонтирован только для чтения; перед изменением требуется осознанно перемонтировать его для записи. После изменений восстановите режим только для чтения.
> - Сведения о файловых системах и защите разделов следует проверять для конкретной прошивки и устройства; не считайте их универсальными без проверки.
